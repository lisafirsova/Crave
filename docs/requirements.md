# Требования проекта
## MVP
MVP — первая рабочая версия приложения, которая содержит основные функции.
## Управление пользователем
* пользователь может зарегистрировать учетную запись
* пользователь может авторизоваться в системе
* пользователь может просматривать и изменять свои данные
## Управление целями
* пользователь может создавать личные цели
* пользователь может указывать описание и дедлайн цели
* пользователь может редактировать созданные цели
* пользователь может удалять цели
* пользователь может просматривать прогресс достижения целей
## AI-планировщик целей
* пользователь может отправить цель для анализа AI
* AI может создавать план достижения цели и разбивать её на подзадачи
* пользователь может просматривать предложенные AI подзадачи перед сохранением
* пользователь может редактировать или удалять созданные AI подзадачи
* пользователь может подтвердить сохранение AI-плана в своей цели
## Игровая система
* пользователь может выполнять подзадачи
* за выполнение подзадач пользователь получает игровую валюту и опыт (XP)
* пользователь может просматривать свой уровень
* пользователь может отслеживать свой прогресс
## Система наград
* пользователь может создавать собственные награды
* пользователь может указывать стоимость награды в игровой валюте
* пользователь может покупать награды за накопленную игровую валюту
* пользователь может просматривать историю полученных наград
## Будущие функции
Функции, которые не входят в первую версию приложения и могут быть добавлены после реализации MVP:
* финансовый трекер с учетом реальных денежных средств
* расширенная система последствий за невыполнение задач
* возможность обсуждать с AI изменение наград и последствий
* стена выполненных целей пользователя
* расширенная статистика прогресса
* уведомления о задачах и целях
* дополнительные AI-функции
