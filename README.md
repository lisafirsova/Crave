# crave
Веб-приложение, которое превращает твои жизненные цели в игру. С нашим веб-сайтом вы сможете: 
* регистрироваться и авторизоваться
* создавать цели, задавать дедлайн для них, а также редактировать и удалять их
* AI добавит в ваши цели подзадачи (вы сможете обсуждать изменение подзадач или удалять их)
* получать игровую валюту за выполнение подзадач и целей, покупать награды
* получать последствия в виде отнятия игровой валюты за несвоев
* ременное выполнение задач
* обсуждать с AI добавление, изменение наказаний и наград (удаление вручную)
### Присоединяйтесь к нам! crave доступно в любом современном браузере.

### Почему для crave требуется учетная запись?
Данные пользователей хранятся в защищенной базе данных. Авторизация реализована с использованием современных механизмов безопасности и необходима для улучшения продукта, а также для того, чтобы при заходе с другого устройства вы не потеряли свой прогресс.
